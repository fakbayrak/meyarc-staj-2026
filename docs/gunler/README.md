# Günlük Staj Dökümanları

Her staj günü sonunda o güne ait doküman burada `gun-NN.md` olarak tutulur
(örn. `gun-01.md`, `gun-02.md`, ...). Her dosyada:

- O gün yapılanlar
- Karşılaşılan sorunlar ve çözümleri
- Öğrenilenler / notlar

yer alır. Plan için bkz. [`staj_defteri_plani.md`](../../staj_defteri_plani.md).
